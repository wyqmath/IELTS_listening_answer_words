# 听见 · 英语听力与词卡练习

[English](README.md) | **简体中文**

一个简洁的英语听力与拼写练习网页，默认附带 **1533 条雅思听力答案词条**，支持听音、中文、音标、词卡、错题本和每日统计。网页默认使用中文。

这套练习系统也可用于四六级或其他英语学习。自备词库没有固定条数限制；给自己的词条标注英文、音标、中文等信息后，即可用同一套网页练习。附带词库是答案词汇汇总，朗读使用合成语音，不是原始试题录音。

## 目录结构

```text
README.md / README.zh-CN.md
index.html 网页入口
app/       样式、脚本、图标与词库
tools/     Windows 启动脚本、标注工具、审核与示例
```

原始学习笔记不随项目保留。正式词库在 `app/data/`，自备词库示例在 `tools/examples/`。

## 打开网页

下载后保留整个文件夹，双击 [`index.html`](index.html) 或 `tools/打开网页.cmd`。推荐 Chrome 或 Edge；日常练习无需安装依赖、注册账号或配置 API。

| 启动文件 | 用途 | 需要什么 |
| --- | --- | --- |
| `tools/打开网页.cmd` | 用默认浏览器打开本地 HTML | 浏览器 |
| `tools/启动本地预览.cmd` | 启动本地服务，访问 `http://127.0.0.1:11545/` | 浏览器、Python 3 |

两个 CMD 是 Windows 启动脚本，任选一种即可。预览服务需保留终端窗口；按 `Ctrl+C` 停止。其他系统可直接打开 HTML，或运行 `python tools/preview_server.py`。网页不会自动刷新。

直接打开文件和 HTTP 服务使用不同的浏览器存储。更换浏览器、路径、端口或打开方式前，请在统计页导出学习备份。

默认白底黑字，使用 Arial 和系统无衬线字体。设置中可选择白底、米白和深色配色，适用于所有页面和全屏；选择会自动保存，并包含在学习备份中。

## 我的练习方式

| 方式 | 怎么练 |
| --- | --- |
| 听音写英文 | 播放发音，输入完整答案；需要时重听。 |
| 看中文写英文 | 根据中文义项写英文，兼顾多义词的常见意思。 |
| 看音标写英文 | 根据英式 IPA 写出完整词形，注意冠词、单复数和时态。 |
| 词卡逐条过 | 一条一条翻卡，查看英文、音标、中文义项、发音备注和同义替换。 |

可以按分类，或选择全部、错题、已标记、尚未练习的词条，并打乱顺序。多义释义在答案和词卡中展示；同义替换默认展开，附对应义项及使用语境，作为学习提示，不自动算作本题正确答案。

四种模式均可朗读，普通和全屏练习都能切换。点击“中文提示”或“音标提示”只改变当前题；勾选“默认中文”或“默认音标”会在之后每题显示，可组合使用。例如听音时加中文和音标，或中文模式加音标并朗读。单题提示切题后恢复默认；当前模式已有的提示不会重复展示。

数字以原数字作为答案展示，同时接受列明的英文读法，例如 `12` 和 `twelve`；音标对应英文读法。时间、日期和编号也保留原形式及有效英文别名。

## 错题与纠错

- 答错立即加入错题本，必须重新拼写正确才能继续；刷新后仍保留未完成纠错。
- 第一次独立作答计入正确率，之后的纠错不提高正确率，也不增加连续答对次数。
- 默认在之后连续独立答对 **3 次**时自动移出错题本；再次独立答错会清零连续次数。
- 设置中可把移出次数改为 1、2、3、4、5 或 10，也支持手动加入、移出及一键清空。
- 清空错题保留标记和历史答题；修改移出次数从下一次独立作答起生效。

答案保留冠词、单复数和时态。大小写、首尾及连续空格、英文单词间的连字符不影响判分；数字负号、小数点和编号前导零仍必须准确。反馈会列出本题可接受的答案形式。

## 键盘与全屏

| 按键 | 操作 |
| --- | --- |
| `Alt+R` | 随时重听，包括输入答案时 |
| `R` | 非输入状态重听 |
| `Space` | 非输入状态播放、暂停或继续 |
| `Enter` | 空白答案时播放；有答案时提交；答对或纠错完成后下一条；词卡中朗读 |
| `Esc` | 收起菜单、关闭弹窗或退出全屏 |

模式、分类、范围、标记、错题操作、上一条、提示和设置集中在可折叠的操作区。普通练习默认展开，全屏默认收起，两种布局分别记住展开状态；收起后已开启的提示和快捷键继续有效。提交和答对后的“下一条”标有 `↵`，题目下方提示当前回车操作。进入词卡、翻卡或切题后，回车会朗读；主动聚焦其他按钮时，回车执行该按钮。输入法选字时不提交，长按回车不会连续切题。

全屏主要展示题目、播放、答案和导航，角落可展开操作或退出。展开操作区后可切换模式、分类和提示。不支持系统全屏的浏览器仍可使用沉浸布局。长释义或较矮屏幕允许滚动；输入和纠错状态不会因退出全屏丢失。

## 声音

使用浏览器 `SpeechSynthesis`，**不预存音频**。设置中可选择音色，调整语速、音高和音量。四种模式切到下一条时默认自动朗读，可手动关闭；已有记录会启用新默认，之后手动关闭的选择会保留。优先选择 `en-GB` 可使用英式英语音色。

语速支持 **0.1–10 倍**，**默认 1 倍**，可拖动或直接输入；实际速度取决于音色。每次播放可设 **1–10 遍**，**默认 2 遍**，适用于播放、重听和所有模式的下一条自动朗读，遍间暂停约半秒。旧记录中的原默认值会自动更新，之后手动修改的值会保留。重听从第一遍开始；换题、切换模式或页面、打开设置／帮助或切到后台会取消剩余播放，空格可暂停和继续。

音量为 **0–100%**，浏览器自带朗读接口不能直接放大到 100% 以上，需要更响时请调整系统或扬声器音量。Google 等音色是否可选、能否离线播放由浏览器和系统决定；遇到朗读失败可换音色或浏览器重试。实际发声须在自己的设备上试听确认。

## 每日统计与备份

统计包括独立答题数、正确率、练过的不同词条、连续学习天数、错题数和活跃练习时长，可按模式、分类、日期筛选。每日表包含答题、正确、错误、纠错、翻卡、时长等；正确率曲线可选 7 天、30 天或全部，没有答题的日期留空。

学习记录保存在当前浏览器的 `localStorage`，支持 JSON 导出和导入；导入会先校验，再确认替换。后台、弹窗和长时间闲置不计练习时长。纠错和翻卡属于学习活动，不计独立答题正确率。

每套词库使用独立 `datasetId`，学习记录及备份按这个标识隔离；备份只能导入对应词库。换一套词库时使用新标识；只修订同一词库的释义时保留标识和稳定条目 ID。默认词库兼容原有学习记录。

## 使用自己的词库

`app/data/vocab.json` 是正式结构化数据，`app/data/vocab.js` 是相同内容的网页加载副本，支持双击 HTML。替换词库需要同步生成这两个文件。

**手动标注**：复制 [tools/examples/vocab.json](tools/examples/vocab.json)，填写完整条目。先在本地目录导出、校验；确认后加 `--replace` 替换网页词库。替换前保存原词库和学习备份。

```sh
python tools/build_vocab.py --input tools/examples/vocab.json --output-dir private/my-vocab
python tools/verify_full.py --data private/my-vocab/vocab.json --js private/my-vocab/vocab.js
python tools/build_vocab.py --input tools/examples/vocab.json --output-dir app/data --replace
```

将命令中的示例输入换成自己的标注 JSON。普通词、短语、专名包含中文义项；数字等可只给英文读法和音标。`acceptedAnswers` 明确列出可接受答案，`synonyms` 单独存学习替换建议。

**可选 API 标注**：参考 [tools/examples/source.json](tools/examples/source.json) 准备原始列表，再用 `tools/full_pipeline.py` 批量生成音标、中文义项及同义建议。接口、模型和密钥只在本地运行时提供，没有固定服务商配置；网页练习不调用标注 API。配置、思考参数及审校方法见 [中文工具说明](tools/README.zh-CN.md) / [English tools guide](tools/README.md)。自动标注仍需要检查释义、读音和答案规则。

默认词库保留原条目、顺序、重复词和稳定 ID，19 条待分类条目已归类。专名的估计读音或不同义项读音会在备注中说明。

## 开发与发布检查

前端为静态 HTML/CSS/JavaScript，无构建步骤。Python 工具使用标准库，需要 Python 3.10 以上。浏览器测试才需要 Node.js、Playwright 和相应浏览器：

```sh
npm --prefix tools ci
npm --prefix tools run test:flows
npm --prefix tools run test:custom
python tools/verify_full.py
python tools/check_public.py
```

以上命令在仓库根目录运行，审核依赖和包配置都放在 `tools/`。测试使用独立后台浏览器，结果默认写入系统临时目录。完整流程审核针对附带的雅思词库；自定义词库审核使用示例数据，验证复用、判分和记录隔离。

`.gitignore` 只允许网页、正式词库、示例、文档和工具进入 Git；原始笔记、标注中间文件、日志、报告、学习备份与实际 API 配置排除在外。发布检查扫描候选文件、暂存内容和 Git 历史，报告仅显示文件名及问题类别。更改后应重新运行检查，并核对实际暂存文件。
